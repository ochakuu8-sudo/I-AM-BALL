# Rolling Town — 坂道の街

Blenderで作った住宅街をボールで走り、体当たりで壊せる、PC・スマートフォン向けのThree.js試作です。
公開URL: https://ochakuu8-sudo.github.io/I-AM-BALL/

リポジトリ: https://github.com/ochakuu8-sudo/I-AM-BALL

## 操作

| 操作 | PC | スマートフォン |
| --- | --- | --- |
| 移動 | WASD / 方向キー | 左のスティック |
| ジャンプ | Space | JUMP |
| ブレーキ | Shiftを押し続ける | BRAKEを押し続ける |
| カメラを回転 | 画面をドラッグ | スティック・ボタン以外の画面をスライド |
| カメラを正面に戻す | C / 右上の照準アイコン | 右上の照準アイコン |
| スタート地点に戻る | R / 右上のリセット | 右上のリセット |
| 一時停止 | P / 右上の一時停止 | 右上の一時停止 |

移動はカメラ基準です。カメラを回しても、スティックを上へ倒すと画面の奥へ進みます。左指で移動しながら、別の指で視点を動かせます。スライドの回転方向は上下・左右とも反転しています。上下の視点角度には制限があり、ボールからカメラまでの距離は固定です。建物や地形による自動接近・近距離の画角補正・建物の透明化は行いません。視界が遮られたらスライドで視点を変えられます。画面から離れると自動で一時停止します。縦・横画面に対応しています。
音は初期状態でオフ。音ボタンでジャンプ音・破壊音を有効にできます。

勢いをつけて壁、木箱、車、木、街灯、植栽などにぶつかると壊れます。木箱は弱く押すと転がり、強くぶつかると板に割れます。家は壁・床・屋根・ベランダ・基礎に分割してあり、壁を抜いた部分から通り抜けられます。衝突した場所だけが欠け、支えを失った側の上階・屋根が遅れて崩れます。リセットで街全体が元に戻ります。

## 試作の構成

- **TypeScript + Three.js**: 街・ボール・追従カメラを描画。
- **Rapier**: 球、坂、家、車、ジャンプ台、動く木箱・コーンの当たり判定。1/60秒固定更新と描画補間。
- **React + Vite**: 画面上の操作パネルと静的ビルド・プレビュー環境。ゲーム本体はクライアントで動作し、ゲーム用バックエンドは不要。
- 配布時は`dist/client`へHTML・JavaScript・GLBを静的出力します。Three.jsと物理処理は`lib/town`に独立させています。
- **Blender 5.2**: 屋根・窓枠・玄関・バルコニー・雨どいなどをモデリング。家の3色の派生から14棟の街区を構成。

球には慣性を残しつつ、加速・旋回を補助しています。視点は球の回転から独立し、ドラッグ操作で360度回せます。移動・視点・ブレーキはそれぞれ指のIDを保持し、指を離す・キャンセル・一時停止の際に入力を解除します。
破壊はRapierの接触位置・衝撃量・壁へ向かう速度で決めます。壁本体と装飾を別のメッシュにし、無傷の壁は一枚のまま描画します。最初に当たった壁だけ、Blender側のスクリプトで事前生成した12区画の不規則な分割へ切り替えます。衝突箇所に近い区画を外し、残った区画には閉じた断面と凸形状の当たり判定を持たせます。穴に重なる窓まわりの装飾も外れます。強打ではボールが通れる穴、浅い角度では小さな欠けができます。区画間のつながりと隣の壁を確認し、支えのない残片も落とします。道路・地形・ジャンプ台は固定です。

上階・床・屋根・ベランダは、近くの壁への支えの関係から崩壊を判定します。下側は約0.2秒、屋根は約0.38秒遅れて落ち始めます。壁や屋根は元の大きな形を保ち、強く着地した壁は元の12区画へ割れます。屋根の着地には追加の欠片を出し、大きな屋根面は残します。車・木・ベンチ・街灯も意味のある元の部品を残して崩れ、木箱・植木鉢などは専用の破片へ置き換えます。

飛散する小片は約0.5〜0.8秒で強く減速して消え、中片は一度跳ねて約1.3〜1.9秒残ります。元の壁・屋根などの塊は最大約4.4秒、割れた壁の区画は約3秒残ります。接触地点から弾ける欠片、落ちる部品、着地の追加破片を組み合わせています。音は衝突・崩れ始め・着地を分け、木・金属・石材の音色を変えています。同時発音と連打の間隔を制限し、消音中のイベントは後で再生しません。

動く構造部品は最大128個、装飾的な破片は最大384個です。Rapierの動的破片は構造部品20個と装飾破片4個の合計24個に制限し、ボディを再利用します。大きな壁・屋根を優先し、残りは地面の高さを使う簡易運動に切り替えます。大きな面はボールの通り道を塞がず、小さな壁の破片は飛び始めから0.2秒後にボールと衝突するようになります。破片同士は衝突しません。元のモデル・壁の区画・小片は形ごとにInstancedMeshへまとめ、不透明のまま縮小して消します。リセットは穴、追加した当たり判定、崩落待ち、動く塊、小片を消して街を復元します。

破壊して飛び散る動きを優先し、全端末で影・3Dオブジェクトの半透明化・UIの背景ぼかしを省いています。半透明用の複製メッシュは生成せず、破片の表示更新も不透明メッシュだけに行います。ボールの丸い影も描画しません。面ごとの照明による立体感と鮮やかな色は維持しています。

配色は黄・青・コーラルの家、青や赤の屋根、鮮やかな植栽で構成しています。道路は彩度を抑え、赤と白のボールが見つけやすいようにしています。Blenderの色指定はsRGBからリニア値へ変換して書き出し、ブラウザでは白飛びと過度な霧を抑えています。モデルの内容から読み込みURLのバージョンを生成し、更新後に古い色のモデルがキャッシュから残りにくくしています。

## 起動と確認

Node.js 22.13以降とnpmを使用します。

```sh
npm ci
npm run dev -- --host 0.0.0.0
```

表示されたlocalhost URLを開きます。同じLANのスマートフォンではPCのLAN IPアドレスと同じポートを使用します。

```sh
npm run test:physics
npm run test:fragments
npm run test:structure
npm run test:controls
npm run test:assets
npm run lint:game
npx tsc --noEmit
npm run build
```

`scripts/test-physics.mjs`は、坂の接地・加速旋回ブレーキ・ジャンプ・入力の先行受付・家の部分破壊・木箱の移動と破壊・時間差のある崩壊・破壊イベントの上限・ジャンプ台・リセット・描画頻度の違いを13シナリオで確認します。数値結果は`art/physics-report.json`に保存されます。
`scripts/test-fragments.mjs`は大小の飛び方・元の色の継承・物理破片がある状態での壁の通り抜け・崩壊時の発生数・連続破壊時の上限と寿命・リセット・描画頻度による差がないことを7シナリオで確認します。数値結果は`art/fragments-report.json`に保存されます。
`scripts/test-structure.mjs`は分割形状の面積・穴の大きさと残った壁の衝突・角への衝突と繰り返し破壊・回転した壁・位置に応じた崩壊・着地での再破壊・負荷上限とリセット・不透明な描画を8シナリオで確認します。結果は`art/structure-report.json`へ保存されます。
`scripts/test-controls.mjs`は4方向のカメラに対する移動を実際の物理で検証し、上下・左右のスライド方向、指の取り違え・キャンセル・上下角の制限・視点リセットを確認します。`scripts/test-assets.mjs`はすべての破壊パーツについて、GLBの位置・回転・大きさと当たり判定が一致すること、色とメッシュ共有が保たれていることを検証します。
ブラウザのWebMCP対応環境では、状態取得・一時停止/再開・リセットも利用できます。未対応環境でもゲームは動作します。

## GitHub Pagesへの公開

`main`にpushすると、GitHub Actionsが型検査・ゲーム部分のlint・物理・操作・アセットのテスト・静的ビルドを実行し、成功した出力だけをGitHub Pagesに公開します。手動実行はActionsの「Deploy GitHub Pages」から行えます。

ワークフローは`.github/workflows/pages.yml`です。配信ファイルは`dist/client`、ビルド時の`PAGES_BASE_PATH`は`/I-AM-BALL`です。ローカル開発ではこの環境変数を指定せず、ルートURLから動作します。

GitHubリポジトリのSettings → Pages → Build and deploymentは「GitHub Actions」を使用します。追加のサービス用APIキーは不要です。

## Blenderとアセット

| ファイル | 内容 |
| --- | --- |
| `art/hillside-house.blend` | 編集できる家のBlenderシーン |
| `art/rolling-town.blend` | 街全体のBlenderシーン |
| `art/hillside-house.png` | 家のBlenderレンダリング |
| `art/town-overview.png` | 街全体のBlenderレンダリング |
| `art/build_town.py` | 家・街・小物を生成し、GLBを出力するスクリプト |
| `art/fracture_patterns.py` | 閉じた壁の12区画を事前生成 |
| `art/destruction.py` | 壁・屋根などの分割、頂点カラーと物理配置の出力 |
| `public/models/town.glb` | 地形の固定メッシュと1,000個以上の独立した破壊パーツ |
| `public/models/house.glb` | 家単体のモデル |
| `public/models/colliders.json` | 地形・建物・車・小物の物理配置 |
| `lib/town/simulation.ts` | 物理、加速、旋回、ジャンプの調整値 |
| `lib/town/game.ts` | Three.js描画とカメラ |
| `lib/town/fracture.ts` | 大小の破片・材質ごとの形・個数制限・物理ボディの再利用 |
| `lib/town/structure.ts` | 壁の区画形状と、大きな部品の落下・物理計算の上限 |
| `lib/town/structure-visual.ts` | 残った壁・飛散する壁区画の描画 |
| `lib/town/controls.ts` | カメラのドラッグ入力と視点基準の移動方向 |

```sh
blender --background --factory-startup --python art/build_town.py
```

Blender実行ファイルがPATHにない場合は、その絶対パスを指定します。実行すると上記モデル・Blenderシーン・確認用画像を再生成します。
家の画像はBlenderのレンダリングであり、ブラウザ画面のスクリーンショットではありません。
